# Seath — Phoenix Server

This is the Phoenix application server for Seath. See the [root README](../README.md) for the full project overview.

## Quick Start

```bash
mix setup     # install deps, create DB, run migrations, seed data
mix phx.server
```

Now visit [`localhost:4000`](http://localhost:4000).

## Development

```bash
mix test                         # run tests
mix compile --warnings-as-errors # check for warnings
mix format                       # format all Elixir files
```
